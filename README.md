# Hi, I'm Philipp!

I'm a student in IT and engineering who likes to make apps and games and tinker around with Raspberry Pi and electronics. You can find some of my creations here, some others on [my website](https://iqnite.github.io/). I mainly code in Python, but also use C++, C#, and TypeScript frequently. My IDE of choice is Visual Studio Code.
